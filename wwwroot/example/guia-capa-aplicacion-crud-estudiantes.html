🎓 Construcción del CRUD de Estudiantes

Capa Application/Services en Blazor Server

🎯 Objetivo de esta guía:
Aprender a construir una capa de servicios completa que implemente todas las operaciones CRUD (Create, Read, Update, Delete) para la entidad Estudiante, utilizando los repositorios disponibles y siguiendo los principios de separación de capas.

1 Crear EstudianteService e IEstudianteService

Objetivo: Crear la interfaz que define los contratos del servicio y la clase que los implementa con toda la lógica de negocio para el CRUD de Estudiantes.
📋 Métodos a implementar:
Basándote en los métodos disponibles en IRepository<T> e IEstudianteRepository, debes crear estos métodos:
  • GetAll() - Obtener todos los estudiantes
  • GetByIdAsync(int id) - Obtener estudiante por ID
  • GetByMatriculaAsync(string matricula) - Obtener por matrícula
  • CreateAsync(EstudianteDto dto) - Crear nuevo estudiante
  • UpdateAsync(int id, EstudianteDto dto) - Actualizar estudiante
  • DeleteAsync(int id) - Eliminar estudiante

Estructura de IEstudianteService:

// Application/Services/IEstudianteService.cs
using LP3.BlazorServer.Shared.DTOs;

namespace LP3.BlazorServer.Application.Services;

public interface IEstudianteService
{
    Task<ICollection<EstudianteDto>> GetAll();
    Task<EstudianteDto?> GetByIdAsync(int id);
    Task<EstudianteDto?> GetByMatriculaAsync(string matricula);
    Task<bool> CreateAsync(EstudianteDto dto);
    Task<bool> UpdateAsync(int id, EstudianteDto dto);
    Task<bool> DeleteAsync(int id);
}

Estructura de EstudianteService:

// Application/Services/EstudianteService.cs
using LP3.BlazorServer.Data.Repositories;
using LP3.BlazorServer.Domain.Entities;
using LP3.BlazorServer.Shared.DTOs;
using LP3.BlazorServer.Shared.Extensions;

namespace LP3.BlazorServer.Application.Services;

public class EstudianteService(IEstudianteRepository estudianteRepository) : IEstudianteService
{
    public async Task<ICollection<EstudianteDto>> GetAll()
    {
        var estudiantes = await estudianteRepository.ListAsync();
        return estudiantes.Select(e => e.ToDto()).ToList();
    }

    public async Task<EstudianteDto?> GetByIdAsync(int id)
    {
        var estudiante = await estudianteRepository.GetByIdAsync(id);
        return estudiante?.ToDto();
    }

    public async Task<EstudianteDto?> GetByMatriculaAsync(string matricula)
    {
        var estudiante = await estudianteRepository.GetByMatriculaAsync(matricula);
        return estudiante?.ToDto();
    }

    public async Task<bool> CreateAsync(EstudianteDto dto)
    {
        try
        {
            var estudiante = new Estudiante
            {
                Nombre = dto.Nombre,
                Apellido = dto.Apellido,
                Matricula = dto.Matricula,
                //Email = dto.Email,
                FechaIngreso = DateTime.UtcNow,
                Estado = Domain.Enums.EstadoEstudiante.Activo
            };

            await estudianteRepository.AddAsync(estudiante);
            return true;
        }
        catch
        {
            return false;
        }
    }

    public async Task<bool> UpdateAsync(int id, EstudianteDto dto)
    {
        try
        {
            var estudiante = await estudianteRepository.GetByIdAsync(id);
            if (estudiante == null) return false;

            estudiante.Nombre = dto.Nombre;
            estudiante.Apellido = dto.Apellido;
            //estudiante.Email = dto.Email;
            estudiante.ActualizadoEn = DateTime.UtcNow;

            await estudianteRepository.Update(estudiante);
            return true;
        }
        catch
        {
            return false;
        }
    }

    public async Task<bool> DeleteAsync(int id)
    {
        try
        {
            var estudiante = await estudianteRepository.GetByIdAsync(id);
            if (estudiante == null) return false;

            await estudianteRepository.Remove(estudiante);
            return true;
        }
        catch
        {
            return false;
        }
    }
}
💡 Tip: Fíjate que usamos ToDto() para convertir entidades a DTOs. Esta extensión ya debe existir en Shared/Extensions/EstudianteExtensions.cs

2 Registrar el Servicio en Program.cs

Objetivo: Configurar la inyección de dependencias para que el servicio esté disponible en toda la aplicación.

¿Dónde agregar?

⚠️ Ubicación correcta: En el método CreateHostBuilder() o en las líneas donde se configuran otros servicios, generalmente después de registrar los repositorios.
// Program.cs - Dentro de builder.Services
// Repositorios (ya debería estar)
builder.Services.AddScoped<IEstudianteRepository, EstudianteRepository>();

// Servicios (agregar esto)
builder.Services.AddScoped<IEstudianteService, EstudianteService>();
ℹ️ Explicación:
  • AddScoped<Interface, Implementación>() - Registra el servicio
  • Se crea una nueva instancia por cada request HTTP
  • La interfaz permite inyectarla como dependencia en otras clases
💡 Orden de registro: Generalmente primero repositorios, luego servicios que dependen de ellos.

private async Task BuscarPorMatricula()
{
    if (string.IsNullOrWhiteSpace(matriculaBusqueda))
    {
        mensajeRegistro = "Por favor ingresa una matrícula";
        return;
    }

    estudianteBuscado = await EstudianteService.GetByMatriculaAsync(matriculaBusqueda);
    
    if (estudianteBuscado == null)
    {
        mensajeRegistro = "❌ No se encontró un estudiante con esa matrícula";
    }
}

// Agregar este método en @code
private async Task RegistrarEstudiante()
{
    if (string.IsNullOrWhiteSpace(nuevoEstudiante.Nombre) ||
        string.IsNullOrWhiteSpace(nuevoEstudiante.Apellido) ||
        string.IsNullOrWhiteSpace(nuevoEstudiante.Matricula)
        // || string.IsNullOrWhiteSpace(nuevoEstudiante.Email)
        )
    {
        mensajeRegistro = "⚠️ Por favor completa todos los campos requeridos";
        return;
    }

    bool resultado = await EstudianteService.CreateAsync(nuevoEstudiante);

    if (resultado)
    {
        mensajeRegistro = "✅ Estudiante registrado exitosamente";
        nuevoEstudiante = new(); // Limpiar formulario
        await CargarEstudiantes(); // Actualizar lista
    }
    else
    {
        mensajeRegistro = "❌ Error al registrar el estudiante. Verifica que la matrícula sea única";
    }
}

// Agregar estos métodos en @code
private void CargarParaEditar(EstudianteDto estudiante)
{
    editandoEstudiante = new EstudianteDto
    {
        Id = estudiante.Id,
        Nombre = estudiante.Nombre,
        Apellido = estudiante.Apellido,
        //Email = estudiante.Email,
        Matricula = estudiante.Matricula
    };
    idEstudianteEditando = estudiante.Id;
}

private async Task GuardarCambios()
{
    if (editandoEstudiante == null) return;

    bool resultado = await EstudianteService.UpdateAsync(idEstudianteEditando, editandoEstudiante);

    if (resultado)
    {
        mensajeRegistro = "✅ Estudiante actualizado exitosamente";
        editandoEstudiante = null;
        idEstudianteEditando = 0;
        await CargarEstudiantes();
    }
    else
    {
        mensajeRegistro = "❌ Error al actualizar el estudiante";
    }
}

private void CancelarEdicion()
{
    editandoEstudiante = null;
    idEstudianteEditando = 0;
}

private void ConfirmarEliminar(int id)

private async Task EliminarEstudiante()
{
    bool resultado = await EstudianteService.DeleteAsync(idEstudianteAEliminar);

    if (resultado)
    {
        mensajeRegistro = "✅ Estudiante eliminado exitosamente";
        mostrarConfirmacionEliminar = false;
        idEstudianteAEliminar = 0;
        await CargarEstudiantes();
    }
    else
    {
        mensajeRegistro = "❌ Error al eliminar el estudiante";
    }
}

private void CancelarEliminar()
{
    mostrarConfirmacionEliminar = false;
    idEstudianteAEliminar = 0;
}

! Puntos Clave a Recordar

🔍 Separación de Capas:
  • Presentation (Estudiantes.razor) - Interfaz de usuario
  • Application (EstudianteService) - Lógica de negocio
  • Data (EstudianteRepository) - Acceso a datos
  • Domain (Estudiante entity) - Modelos de negocio
🎯 Métodos Disponibles del Repositorio:
  • ListAsync() - Retorna IReadOnlyList<T>
  • GetByIdAsync(int) - Retorna T? (nullable)
  • GetByMatriculaAsync(string) - Método específico de EstudianteRepository
  • AddAsync(T) - No retorna nada, lanza excepción si falla
  • Update(T) - Actualiza la entidad
  • Remove(T) - Elimina la entidad
💡 DTOs vs Entities:
  • Las Entities representan los datos en la BD (con relaciones complejas)
  • Los DTOs (Data Transfer Objects) son versiones simplificadas para transferir datos
  • Usa la extensión .ToDto() para convertir entre ellos
⚠️ Validaciones Importantes:
  • Siempre valida que los campos requeridos no estén vacíos
  • Usa try-catch para manejar excepciones en el servicio
  • Verifica si el estudiante existe antes de actualizar o eliminar
  • Muestra mensajes claros al usuario sobre éxito o error
